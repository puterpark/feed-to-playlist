개인정보처리방침

시행일: 2026-11-11

Feed to Playlist(이하 "서비스")는 이용자가 구독한 YouTube 채널의 새 영상을 이용자의 재생목록에 자동으로 추가하는 서비스입니다. 이 방침은 서비스가 어떤 정보를 수집하고, 어떻게 사용·보관·파기하는지 설명합니다.

1. 수집하는 정보

이용자가 Google 계정을 연결하면 Google 이 제공하는 다음 정보를 수집합니다.

항목 내용
계정 식별 정보 Google 계정의 고유 ID(sub), 이메일 주소
인증 토큰 서비스가 이용자를 대신해 YouTube API 를 호출하기 위한 refresh token (암호화하여 저장)
YouTube 구독 정보 구독 중인 채널의 ID 와 채널 이름
재생목록 정보 서비스가 만들거나 찾은 대상 재생목록의 ID
처리 이력 이미 처리한 영상의 ID (같은 영상을 중복 추가하지 않기 위한 기록)

서비스는 영상 시청 기록, 좋아요, 댓글, 이용자의 개인 영상 파일 등은 수집하지 않습니다. 웹사이트에서 광고·분석용 쿠키나 추적 도구를 사용하지 않으며, OAuth 연결 과정의 보안(CSRF 방지)을 위한 임시 세션만 사용합니다. 서비스는 만 14세 미만 아동을 대상으로 하지 않으며, 만 14세 미만의 이용자는 서비스를 이용할 수 없습니다.

2. 이용 목적

  • 구독 중인 채널의 새 영상을 확인하여 이용자의 재생목록에 추가하는 서비스 제공
  • 연결된 계정의 식별 및 인증 상태 관리
  • 중복 추가 방지와 오류 처리

수집한 정보는 위 목적 외에는 사용하지 않습니다.

3. Google 사용자 데이터 이용 (Limited Use)

서비스가 Google API 로부터 받은 정보를 다른 앱으로 전송하거나 사용하는 행위는 Google API 서비스 사용자 데이터 정책 (제한적 사용 요구사항 포함)을 준수합니다. 구체적으로:

The use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

  • Google 사용자 데이터는 이용자에게 보이는 기능(구독 영상의 재생목록 자동 추가)을 제공하는 목적으로만 사용합니다.
  • Google 사용자 데이터를 제3자에게 판매하거나 광고(개인 맞춤 광고 포함)에 사용하지 않습니다.
  • 법령 준수, 보안 사고 조사, 합병·인수 등 법적으로 필요한 경우를 제외하고는 제3자에게 공유·이전하지 않습니다.
  • 사람이 이용자의 데이터를 열람하지 않습니다. 단, 이용자의 명시적 동의가 있거나 보안상 필요하거나 법령상 요구되는 경우는 예외입니다.
  • Google 사용자 데이터를 일반적·비개인화된 AI/ML 모델의 학습에 사용하지 않습니다.

4. YouTube API 서비스

서비스는 YouTube API 서비스를 사용합니다. 서비스를 이용함으로써 이용자는 YouTube 서비스 약관과 Google 개인정보처리방침에 구속됨에 동의합니다.

5. 보관과 보안

  • 인증 토큰은 암호화하여 저장하며, 수집한 정보는 안전하게 보호하여 보관합니다.
  • 이용자의 Google 비밀번호는 서비스에 전달되거나 저장되지 않습니다.
  • 정보는 서비스를 이용하는 동안 보관하며, 다음 중 먼저 도래하는 시점에 지체 없이(늦어도 7일 이내) 파기합니다. (1) 이용자가 Google 계정에서 서비스의 접근 권한을 해제한 때, (2) 이용자가 삭제를 요청한 때, (3) 서비스를 종료한 때
  • 파기는 데이터베이스에서 해당 정보를 삭제하는 방식으로 하며, 삭제한 정보는 복구할 수 없습니다.
  • 법령에 따라 보존해야 하는 정보가 있는 경우에는 해당 기간 동안 별도로 보관한 뒤 파기합니다.

6. 제3자 제공 및 처리 위탁

서비스는 이용자의 정보를 제3자에게 판매하거나 제공하지 않습니다. 서비스 제공에 필요한 범위에서 Google(YouTube) API 로만 데이터를 주고받습니다. 서버·데이터베이스 운영을 위해 호스팅 사업자의 인프라를 이용할 수 있으며, 이 경우에도 사업자가 이용자의 정보를 자기 목적으로 이용하지 못하도록 합니다.

7. 연결 해제와 데이터 삭제

이용자는 언제든지 다음 방법으로 서비스 이용을 중단하고 정보를 삭제할 수 있습니다.

  1. Google 계정 권한 관리에서 Feed to Playlist 의 접근 권한을 삭제합니다. 그러면 서비스는 더 이상 이용자의 YouTube 계정에 접근할 수 없습니다.
  2. 저장된 정보(이메일, 암호화된 토큰, 구독 정보, 처리 이력)의 삭제를 원하면 아래 문의처로 요청하세요. 요청을 확인한 날부터 7일 이내에 삭제하며, 삭제 후에는 복구할 수 없습니다.

서비스가 만든 재생목록은 이용자의 YouTube 계정에 남아 있으므로, 필요하면 YouTube 에서 직접 삭제하세요.

8. 이용자의 권리

이용자는 자신의 정보에 대해 열람, 정정, 삭제, 처리 정지를 요청할 수 있습니다. 문의처로 요청해 주세요.
